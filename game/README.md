# 219-Empire — Game (Phaser 3 prototype)

This folder contains a small HTML5 prototype for "219-Empire" — a Coin Master–style single-player browser game themed on Northwest Indiana with Michigan City as the starting town.

Run locally: open game/index.html in a browser (or use a static server like `npx http-server game`).

Structure:
- index.html — game container and Phaser loader
- src/main.js — Phaser game code: scene, UI, spin mechanic, coin counter, building buy
- assets/ — placeholder sprites and icons
- README.md — this file
- DESIGN.md — short design notes and next steps
